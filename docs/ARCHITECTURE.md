# Architecture

SwiftPM package, two targets plus tests. No Xcode project; `scripts/build-app.sh` wraps the binary in an `.app` bundle.

```
Sources/
  ShotNamerCore/        pure logic, no UI, unit-tested
    FileNamer.swift     is-it-a-screenshot, parse capture time, sanitize, build name, pick unique path
    AppHistory.swift    "which app was frontmost at time T"
    TextRecognizer.swift  Vision OCR → text lines with position; biggest-text fallback
    SiteDetector.swift  domain from the address-bar text; browser check; redundancy check
    SensitiveDetector.swift  regex finders (e-mail, IBAN, card, tokens, labelled secrets); scrub()
    Redactor.swift      black boxes via CoreGraphics, format/DPI/profile preserved, atomic swap; backup purge
    SearchIndex.swift   OCR text → Finder-comment xattr (kMDItemFinderComment) for Spotlight
    SortMode.swift      month / source folder paths for sorting
    Template.swift      {token} engine: missing tokens drop their separator; validity check (no rename loops)
    UndoLog.swift       JSON list of renames in ~/Library/Application Support/ShotNamer/
    Renamer.swift       screenshot folder lookup, rename + log, undo
  ShotNamer/            the menu bar app (SwiftUI MenuBarExtra)
    ShotNamerApp.swift  menu UI + settings window scene
    SettingsView.swift  settings form
    AppModel.swift      wires watcher, app-activation tracking, rename, undo
    WindowTitle.swift   focused-window title via Accessibility API
    FolderWatcher.swift DispatchSource on the folder; reports new screenshot files
Tests/ShotNamerCoreTests/
Resources/Info.plist    LSUIElement (no Dock icon), folder-access usage strings
Resources/AppIcon.icns  app icon (generated by scripts/make-icon.sh from scripts/make-icon.swift)
scripts/build-app.sh    swift build → .app → ad-hoc codesign
scripts/install.sh      build-app + copy to /Applications + restart
```

## Flow

1. **Start.** `AppModel` resolves the screenshot folder (`com.apple.screencapture location`, else `~/Desktop`; `SHOTNAMER_FOLDER` overrides for tests), snapshots the existing file names so they are never touched, and starts listening to `NSWorkspace.didActivateApplicationNotification`. The current frontmost app seeds `AppHistory`.
2. **Detect.** `FolderWatcher` gets a directory `.write` event, lists the folder and diffs against the names it has seen. New names that pass `FileNamer.isScreenshot` are reported.
3. **Settle.** macOS may still be writing the file, so `AppModel.waitUntilStable` waits until its size stops changing (500 ms polls, 10 s cap). Recordings wait for 3 unchanged 1 s polls *and* a loadable `AVURLAsset` duration > 0 (the movie index is written last), for up to 10 minutes.
4. **Identify.** Capture time comes from the digits in the filename (works in any locale, 12 h or 24 h). The file's own creation date is only a fallback, because the floating screenshot thumbnail can delay writing the file by seconds. `AppHistory.app(at:)` returns the app active at that time. A 1 s timer records the focused window title into a second `AppHistory`, so the title at capture time is looked up the same way. `com.apple.screencaptureui` and ShotNamer itself are never recorded.
5. **Rename.** One OCR pass (off the main thread). If the app is a browser, `SiteDetector.domain` picks the domain: a match in the top 20% of the image (the address bar) wins, else the most frequent domain; subdomains collapse (`docs.github.com` → `github.com`). Then the window title (dropped if it only repeats the site), else the optional biggest-text fallback → `FileNamer.makeName` → `uniqueURL` → move → append to `UndoLog`.
6. **Undo.** `Renamer.undoLast` pops the newest log entry and moves the file back, refusing to overwrite an existing file.

## Redaction

Opt-in. In `Renamer.rename`, after the single OCR pass: (1) lines are scrubbed of sensitive matches, and a window title containing one is dropped, so neither the file name nor the Spotlight comment can leak it; (2) for images, `Redactor.regions` maps each match to a box (`VNRecognizedText.boundingBox(for:)` on the exact OCR string, falling back to the whole line); (3) the original is copied to `Originals/<uuid>-<name>` and recorded in the undo log; (4) `Redactor.blackOut` redraws the image at pixel size with the source's properties and swaps it in with `replaceItemAt` from a dot-prefixed temp file (the watcher ignores dot files). It refuses to run without a backup location. `undoLast` restores the backup over the renamed-back file. Backups older than 7 days are purged at launch.

## Decisions

- **No rename loops.** Three layers: the default template starts with a date; `Template.isValidName` rejects custom templates whose output looks like a screenshot (so the default is used); and `AppModel` remembers every path it wrote and ignores it if the watcher reports it again.
- **Accessibility for titles, not Screen Recording.** Reading a window title via AX needs only the Accessibility permission and avoids the recording-indicator prompt. OCR was the first attempt for the text part but picked ads and placeholders, so it is only a fallback.
- **Site from OCR, not Accessibility.** The address bar is in the screenshot, so OCR needs no permission and also works for sites the user can see but the browser does not expose. A restricted TLD list and browser-only scanning avoid false positives (e-mail addresses, numbers like `13.797.610`).
- **On-device OCR only.** Apple Vision; no network code anywhere.
- **Swift 5 language mode** inside a `swift-tools-version:6.0` package, to avoid strict-concurrency churn for a small app. Revisit when moving to Swift 6 mode.
- **Ad-hoc signing.** No Developer ID yet, so no notarization; see README for the Gatekeeper consequence.

## Testing

`swift test` covers naming, locale parsing, the no-loop invariant, app lookup, rename/undo/collisions. The folder watcher and UI are checked by running the app on a scratch folder:

```sh
mkdir /tmp/shots
SHOTNAMER_FOLDER=/tmp/shots build/ShotNamer.app/Contents/MacOS/ShotNamer &
cp some.png "/tmp/shots/Screenshot 2026-11-24 at 2.32.10 PM.png"
ls /tmp/shots
```
